# 公开版本验证

## Mac 0.6.3：中文空白修复（2026-11-11）

- 旧版界面、对话、状态栏和世界标签通过 SystemFont 查找系统字体；字体未随应用分发。用户报告场景、面板正常但文字空白，标题宋体仍能显示。此次将正文统一为内置 Noto Sans CJK SC，标题统一为内置 Noto Serif CJK SC；关闭两字体的系统回退。
- Godot 4.7.2 干净导入、原有 `tests/smoke.gd`、新增 `tests/fonts.gd` 均通过。新增检查在禁用系统回退的条件下核实字体数据、字符宽度、游戏数据中 1,644 个不同可见字符，以及正式控件/自绘 HUD/世界标签实际引用的字体。
- 实际解压的 macOS 正式导出包经系统鼠标/键盘打开，目视确认标题、副标题、两个按钮、操作提示、序章正文、新游戏地图名、角色名、等级、生命/真气数值、人物对话和继续按钮均能显示；连续点击对话可更新文本。
- Mac 通用程序含 arm64 和 x86_64，临时签名完整性检查通过。本次实际运行平台为 Apple 芯片；Intel Mac 未单独实测，未做 Apple 公证。Windows 0.6.2 下载保持不变。
- 没有改动剧情、战斗数值、存档格式或公开版 `FMJClassic` 用户目录。本次没有重跑全流程通关，也没有覆盖玩家存档。用户提供的私有旧应用保留，修复通过独立公开版交付。
- 字体许可全文随源码、游戏资源包和下载 ZIP 一并交付；字体来源及文件校验见 `assets/fonts/SOURCES.md`。构建入口会先运行字体检查，失败即停止导出。
